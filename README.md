## 📌 Descripción de la Materia
**Programación IV** es una asignatura orientada al diseño, arquitectura y construcción de aplicaciones multiplataforma, con un **objetivo principal enfocado en el desarrollo móvil**. A través del estudio de frameworks modernos, paradigmas de programación reactiva y gestión de estados, el curso capacita al estudiante para conceptualizar, desarrollar, probar y desplegar software móvil eficiente y escalable.

---

## 🚀 Tecnologías y Herramientas del Curso (Con Concepto Propio)

### 1. Kotlin y Android Studio
* **Concepto Propio:** Kotlin es el lenguaje moderno, conciso y tipado estáticamente por excelencia para el ecosistema nativo de Android. Al combinarlo con Android Studio, permite un control absoluto sobre el ciclo de vida de las aplicaciones, la optimización de recursos en hardware móvil y la implementación de interfaces nativas fluidas utilizando Jetpack Compose y buenas prácticas de arquitectura (como MVVM).

### 2. React Native y Expo
* **Concepto Propio:** React Native representa la eficiencia del desarrollo multiplataforma basada en JavaScript y TypeScript, permitiendo compilar código nativo real tanto para Android como para iOS a partir de una base de código unificada. Complementado con Expo, simplifica enormemente la gestión de dependencias nativas, el flujo de compilación (OTA updates) y el despliegue rápido de prototipos funcionales y aplicaciones de producción.

### 3. Flutter y Dart
* **Concepto Propio:** Flutter es un framework de Google impulsado por Dart que destaca por su motor gráfico propio (Skia/Impeller), el cual renderiza cada widget píxel a píxel directamente sobre la pantalla. Esto garantiza una consistencia visual impecable y un rendimiento de 60/120 FPS, ideal para interfaces altamente personalizadas y experiencias de usuario fluidas en múltiples sistemas operativos.

### 4. TypeScript y JavaScript moderno (ES6+)
* **Concepto Propio:** TypeScript aporta tipado estático opcional y robustez arquitectónica a JavaScript, minimizando errores en tiempo de compilación y facilitando la mantenibilidad en bases de código móviles complejas. Su integración en frameworks como React Native y NestJS asegura contratos de datos claros entre el cliente móvil y las APIs del backend.

### 5. Arquitectura de Backend (NestJS, Django REST Framework & Node.js)
* **Concepto Propio:** Todo ecosistema móvil requiere un motor de servicios robusto. NestJS y Node.js ofrecen arquitecturas modulares altamente escalables basadas en TypeScript para construir APIs RESTful y sockets en tiempo real. Por su parte, Django REST Framework proporciona un desarrollo rápido y seguro basado en Python, ideal para la gestión de modelos relacionales complejos y autenticación robusta mediante JWT.

### 6. Bases de Datos (PostgreSQL & MongoDB)
* **Concepto Propio:** La persistencia de datos móvil y de servidor se aborda combinando la consistencia transaccional y relacional de PostgreSQL (con soporte para consultas avanzadas y procedimientos almacenados) junto con la flexibilidad orientada a documentos de MongoDB para esquemas dinámicos y de alta disponibilidad.

### 7. Control de Versiones y Entornos (Git, GitHub, Docker y Linux)
* **Concepto Propio:** El estándar profesional de desarrollo se sustenta en Git y GitHub para la gestión de ramas, control de cambios y colaboración en equipo. Asimismo, el uso de entornos Linux y contenedores garantiza la reproducibilidad de los servicios de backend y la estabilidad en los pipelines de despliegue continuo.

## 🎯 Objetivos Específicos de Aprendizaje
1. Diseñar interfaces de usuario adaptativas, intuitivas y centradas en la experiencia de usuario (UX/UI) para dispositivos móviles.
2. Implementar lógica de negocio eficiente y consumo de APIs RESTful mediante arquitecturas limpias.
3. Gestionar almacenamiento local y persistencia de datos en entornos móviles.
4. Aplicar pruebas unitarias y de integración para asegurar la calidad y estabilidad del software móvil.
